**Migration lịch sử các lần thay đổi database, là cách quản lý thay đổi database theo từng phiên bản.
            Ví dụ team có 3 người:
                - Mày tạo bảng todos
                - Tao thêm cột deadline
                - Người khác thêm cột priority
            Nếu không có migration, mỗi người phải nhớ tự chạy SQL trên máy mình. Rất dễ quên hoặc tạo sai.
            Nếu có migration, ai clone project về chỉ cần chạy:
                npx prisma migrate dev
            Prisma sẽ đọc lịch sử:
                001 tạo bảng todos
                002 thêm deadline
                003 thêm priority
            rồi tự làm database giống y chang.

**Code-first: viết cấu trúc database bằng code trước, rồi công cụ tự tạo database/table theo code đó.
        Code-first:
            schema.prisma -> database
        Database-first:
            database -> schema.prisma
